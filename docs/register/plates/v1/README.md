## How to read them

**Copy, after approval.** Header with Trigger, Tower, the commit, the scope, the revision, and Table / Graph. Module groups. Initiative and packet rows with the columns in plate A. Graph containment and the dashed dependency. Detail sections that quote the factory files. Counts. No percentage. No factory button. A running pulse only from a dispatch or a live lease. A blocked reason on that initiative.

**Do not build.** The yellow banner on plate E. Any sentence that exists to teach the plate. Plate E’s dispatch, until a record actually has one. A node that is not in the ledger.

**Implied.** The switch changes view. A row and a node open the detail. Back returns to the view the founder was on. Expanding and collapsing follow the spec. A link opens the factory URL. A failed read keeps the last rows and says so.

**Completes, no extra plate.** Empty ledger: chrome and no rows. Unknown stage word: neutral ink. `hold`, `blockerId`, and `lease` shown once the reader is ascribed, including when they are null. A packet at `accepted` lets its initiative collapse if nothing else keeps it open.

**Out of scope.** Checkpoint transcript. A second factory. Choosing React Flow in this plate. Factory controls. A project switcher. Editing Tower. Treating pull request 136’s merge as an `integratedSha`.
