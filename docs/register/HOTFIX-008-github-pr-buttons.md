# Hotfix 008 — review and merge open the pull request

Founder, 31 Oct 2026, 6:00 PM America/Toronto: Review and Merge should open their GitHub pages. Review is the pull request. Merge only if GitHub has a page for it.

## Cut

- Review on an open release opens that release’s `prUrl` in a new tab. The desk stays on its page.
- When `prUrl` is missing, Review still opens the packet.
- Merge opens the same pull request. GitHub draws the merge control on that page. It does not publish a separate merge address, and this desk does not invent one.
- The desk does not call GitHub’s merge API. Opening the page is the browser. A table row still opens the packet, including the review block.

## Not in this cut

A write token. A merge performed by Trigger. A different pull request than the ledger names.
